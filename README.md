# Fruit Merge

Fruit Merge is a 2048-style puzzle game. Combine matching fruits to make the next fruit and work your way up to a watermelon.

## How to play

- Move all fruits in one direction with the **arrow keys**, **swipe**, or the on-screen direction buttons.
- When two matching fruits meet, they merge into the next fruit: **apples → oranges → bananas → grapes → strawberries → pineapples → kiwis → watermelons**.
- Each successful move adds a new fruit to the board. Plan carefully—the board fills up!
- Make a watermelon to win. The game ends when no more moves are possible.
- Select **New game** to start over.


Arrow keys: Press ↑, ↓, ←, or → to slide all the fruits in that direction.
Swipe: On a touchscreen, swipe across the board in the direction you want to move.
On-screen buttons: Tap an arrow below the board.
New game: Resets the board and score.


Checking the game: The code checks whether you’ve made a watermelon or whether any moves remain. If no moves remain, it displays a game-over message.
